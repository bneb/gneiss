# gneiss-parsers

The multilingual translator of Gneiss. This crate provides high-performance decoders for raw satellite and inertial data protocols.

## Overview

We translate archaic, bit-level protocols into elegant Rust structures so the rest of the engine can focus on the physics.

### Supported Protocols

- **u-blox Binary**: RAWX, SFRBX, and ESF-RAW.
- **RINEX**: Receiver Independent Exchange format (v2 and v3).
- **RTCM3**: Multi-Stage Messages and Ephemeris streams.
